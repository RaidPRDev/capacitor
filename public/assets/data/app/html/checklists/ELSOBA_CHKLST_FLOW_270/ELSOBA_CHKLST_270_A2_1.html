Straight connector sizes
  • Adult / small adult / older (larger) children:
    • ½–⅜ connector for venous line if a ½ venous line was used during CPB
    • OR ⅜–⅜ connector for venous line if a ⅜ venous line was used during CPB
    • ⅜–⅜ connector for arterial line
  • Pediatric:
    • ⅜–¼ connector for venous line if a ⅜ venous line was used during CPB
    • ¼–¼ connector for arterial line
  • Infants:
    • ¼–¼ connectors for venous and arterial lines
  • Neonates:
    • ¼–¼ connector for venous line
    • ³⁄₁₆–¼ connector for arterial line
